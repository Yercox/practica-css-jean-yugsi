# Burger Rush

## Descripción
Sitio web de un restaurante de comida rápida desarrollado como parte de la práctica
"Aplicación de estilos y propiedades CSS" de la asignatura Fundamentos de Sistemas Web.

## Tecnologías utilizadas
- HTML5
- CSS3
- Git
- GitHub

## Funcionalidades
- Presentación del restaurante y navegación entre secciones.
- Combos y catálogo de productos.
- Tabla de precios y disponibilidad.
- Galería de imágenes.
- Formulario de contacto.
- Nueva sección "Nuestra historia" (reto).

## Estructura del proyecto
- index.html
- css/estilos.css
- imagenes/

## Flujo de ramas
- `main`: versión final.
- `despliegue`: versión validada para publicar.
- `desarrollo`: integración de funcionalidades.
- `funcionalidad-inicio`, `funcionalidad-servicios`, `funcionalidad-reto`: ramas de trabajo.
